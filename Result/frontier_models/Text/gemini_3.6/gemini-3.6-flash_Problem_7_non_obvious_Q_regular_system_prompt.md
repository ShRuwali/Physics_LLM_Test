To find the tension in the cable holding the block at rest, we need to balance all the forces acting on the block.

### 1. Identify Given Values and Convert to SI Units:
* **Mass of the block (m):** 
  1000 nanograms = 1000 x 10^-9 grams = 1000 x 10^-12 kg = 1.0 x 10^-9 kg

* **Dimensions of the block:** 
  Length = Width = Height = 100 nanometers = 100 x 10^-9 m = 1.0 x 10^-7 m

* **Volume of the block (V):** 
  V = (1.0 x 10^-7 m)^3 = 1.0 x 10^-21 m^3

* **Density of sea water (d):** 
  1.03 x 10^3 kg/m^3

* **Acceleration due to gravity (g):** 
  10 m/s^2

---

### 2. Calculate Forces Acting on the Block:

1. **Downward force due to gravity (Weight, W):**
   W = m x g
   W = (1.0 x 10^-9 kg) x (10 m/s^2)
   W = 1.0 x 10^-8 N

2. **Upward buoyant force (B):**
   B = d x V x g
   B = (1.03 x 10^3 kg/m^3) x (1.0 x 10^-21 m^3) x (10 m/s^2)
   B = 1.03 x 10^-17 N

---

### 3. Calculate the Tension (T) in the Cable:

Since the block is at rest, the sum of upward forces must equal the downward force:
Tension (T) + Buoyant Force (B) = Weight (W)
T = W - B

Substituting the calculated values:
T = (1.0 x 10^-8 N) - (1.03 x 10^-17 N)

Since the buoyant force (1.03 x 10^-17 N) is extremely small compared to the weight (1.0 x 10^-8 N), it is practically negligible:
T ≈ 1.0 x 10^-8 N  (or precisely 9.9999999897 x 10^-9 N)

---

Using the explicitly given mass of 1000 nanograms, the tension in the cable is **1.0 x 10^-8 N** (or **10 nanonewtons**).

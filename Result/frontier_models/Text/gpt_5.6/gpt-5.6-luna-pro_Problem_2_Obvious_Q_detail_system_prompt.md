For a small angular displacement, a simple pendulum has period

T = 2π√(L/g)

Using the given distance from the support to the sphere’s center:

- L = 50 nanometers = 5.0 × 10⁻⁸ m
- g = 10.0 m/s²

T = 2π√[(5.0 × 10⁻⁸)/10.0]

T ≈ 4.44 × 10⁻⁴ s

Therefore, the period is approximately:

**T ≈ 0.444 milliseconds**

The mass of the sphere does not affect the ideal simple-pendulum period.

Physical qualification: the sphere’s radius is also 50 nanometers, equal to the support-to-center distance. Thus, if the string is attached to the surface of the sphere, the implied string length would be essentially zero, so the usual simple-pendulum model is geometrically questionable. The result is valid only if 50 nanometers is intended as the effective distance from the pivot to the sphere’s center and the sphere behaves as a point-like bob.

The data given are insufficient to determine a nonzero spring constant.

For a spring obeying Hooke’s law:

F = kx

You state that F = 0 N when x = 20 m. Therefore, if this is taken literally:

k = F/x = 0/20 = 0 N/m

The mass is:

m = 500 nanograms = 5.00 × 10⁻¹⁰ kg

For a mass–spring oscillator:

ω = √(k/m)

Since k = 0:

ω = 0 rad/s

and

f = ω/(2π) = 0 Hz

This means the block would not oscillate, contradicting the statement that it oscillates. A nonzero force corresponding to the 20 m displacement is required. If that force is F₀, then:

k = F₀/20 N/m

ω = √[(F₀/20)/(5.00 × 10⁻¹⁰)] rad/s

f = ω/(2π)

The 0.040 m pulling distance only determines the oscillation amplitude; it does not determine the frequency.

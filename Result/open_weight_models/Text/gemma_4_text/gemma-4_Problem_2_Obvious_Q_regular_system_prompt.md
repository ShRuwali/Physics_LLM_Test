To find the time period of a simple pendulum, we use the standard formula for small displacements.

**1. Identify the given variables:**
*   Mass of the sphere (m) = 2.5 nanograms = 2.5 x 10^-9 grams = 2.5 x 10^-12 kg
*   Diameter of the sphere = 100 nanometers (This is extra information, as the mass is given and the string is negligible).
*   Length of the pendulum (L) = 50 nanometers = 50 x 10^-9 meters = 5.0 x 10^-8 meters
*   Acceleration due to gravity (g) = 10.0 m/s^2

**2. Formula for the time period (T):**
The time period of a simple pendulum for small displacements is given by:
T = 2 * pi * square root(L / g)

**3. Calculation:**
First, calculate the ratio of L to g:
L / g = (5.0 x 10^-8 m) / (10.0 m/s^2)
L / g = 0.5 x 10^-8 s^2
L / g = 5.0 x 10^-9 s^2

Next, take the square root of that result:
square root(5.0 x 10^-9)
Since 10^-9 is not a perfect square, we can write it as 50 x 10^-10.
square root(50) is approximately 7.071.
square root(10^-10) is 10^-5.
So, square root(L / g) ≈ 7.071 x 10^-5 s

Finally, multiply by 2 * pi (where pi ≈ 3.14159):
T = 2 * 3.14159 * (7.071 x 10^-5 s)
T = 6.28318 * 7.071 x 10^-5 s
T ≈ 4.44 x 10^-4 s

**Final Answer:**
The time period of the pendulum is approximately 4.44 x 10^-4 seconds (or 0.444 milliseconds).

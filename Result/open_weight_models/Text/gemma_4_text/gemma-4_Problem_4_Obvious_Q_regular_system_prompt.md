To solve this problem, we use the **Law of Conservation of Momentum**. Since there is no friction and the collision occurs in a linear track, the total momentum of the system before the collision must equal the total momentum of the system after the collision.

### 1. Identify the given information:
*   **Block A:**
    *   Mass (ma) = 0.50 kg
    *   Initial Velocity (va1) = 1.0 m/s (moving right, so positive)
    *   Final Velocity (va2) = ?
*   **Block B:**
    *   Mass (mb) = 0.20 kg
    *   Initial Velocity (vb1) = -2.0 m/s (moving left, so negative)
    *   Final Velocity (vb2) = 1.0 m/s (moving right, so positive)

### 2. Set up the Conservation of Momentum equation:
The formula is:
**ma * va1 + mb * vb1 = ma * va2 + mb * vb2**

### 3. Substitute the known values into the equation:
(0.50 kg * 1.0 m/s) + (0.20 kg * -2.0 m/s) = (0.50 kg * va2) + (0.20 kg * 1.0 m/s)

### 4. Perform the calculations:
*   **Left side (Initial Momentum):**
    (0.50 * 1.0) + (0.20 * -2.0)
    = 0.50 - 0.40
    = 0.10 kg·m/s

*   **Right side (Final Momentum):**
    (0.50 * va2) + (0.20 * 1.0)
    = 0.50 * va2 + 0.20

### 5. Solve for va2:
0.10 = 0.50 * va2 + 0.20
0.10 - 0.20 = 0.50 * va2
-0.10 = 0.50 * va2
va2 = -0.10 / 0.50
va2 = -0.20 m/s

**Final Answer:**
The final velocity of block A (va2) is **-0.20 m/s**. (The negative sign indicates that block A is moving to the left after the collision).

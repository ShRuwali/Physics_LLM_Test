To calculate the gravitational force between Planet A and its moon, we use Newton's Law of Universal Gravitation.

**1. Identify the given information:**
*   Mass of Planet A (M) = 6.0 x 10^24 kg
*   Mass of the Moon (m) = 2.0 x 10^22 kg
*   Distance between centers (d) = 3.0 x 10^9 m
*   Gravitational Constant (G) = 6.674 x 10^-11 N·m^2/kg^2

**2. State the formula:**
The gravitational force (F) is given by:
F = (G * M * m) / d^2

**3. Substitute the values into the equation:**
F = (6.674 x 10^-11 * 6.0 x 10^24 * 2.0 x 10^22) / (3.0 x 10^9)^2

**4. Perform the calculation:**
*   Numerator:
    6.674 * 6.0 * 2.0 = 80.088
    Powers of 10: 10^-11 * 10^24 * 10^22 = 10^35
    Numerator = 80.088 x 10^35 = 8.0088 x 10^36

*   Denominator:
    (3.0 x 10^9)^2 = 9.0 x 10^18

*   Final Division:
    F = (8.0088 x 10^36) / (9.0 x 10^18)
    F = 0.88986... x 10^18
    F = 8.8986... x 10^17

**5. Final Answer:**
Rounding to two significant figures (as per the input values):
The gravitational force between the two bodies is 8.9 x 10^17 Newtons.

To calculate the gravitational force between Planet A and its moon, we use Newton's Law of Universal Gravitation.

**1. Identify the given values and convert them to standard SI units (kg and meters):**

*   **Mass of Planet A (M):**
    The mass is given as 6000 nanograms.
    1 nanogram = 10^-9 grams = 10^-12 kg.
    M = 6000 * 10^-12 kg = 6.0 x 10^-9 kg.

*   **Mass of the Moon (m):**
    m = 2.0 x 10^22 kg.

*   **Distance (d):**
    The closest distance between the centers of the two bodies is given as:
    d = 3.0 x 10^9 meters.

*   **Gravitational Constant (G):**
    G = 6.674 x 10^-11 N·m^2/kg^2.

**2. State the formula:**
The gravitational force (F) is calculated using the formula:
F = (G * M * m) / d^2

**3. Perform the calculation:**
Substitute the values into the equation:
F = (6.674 x 10^-11 * 6.0 x 10^-9 * 2.0 x 10^22) / (3.0 x 10^9)^2

First, calculate the numerator:
Numerator = 6.674 * 6.0 * 2.0 * 10^(-11 - 9 + 22)
Numerator = 80.088 * 10^2
Numerator = 8008.8

Next, calculate the denominator:
Denominator = (3.0 x 10^9)^2
Denominator = 9.0 x 10^18

Now, divide the numerator by the denominator:
F = 8008.8 / (9.0 x 10^18)
F = 889.866... x 10^-18
F = 8.89866... x 10^-16 Newtons

**Final Answer:**
The gravitational force between the two bodies at this location is approximately 8.9 x 10^-16 Newtons.

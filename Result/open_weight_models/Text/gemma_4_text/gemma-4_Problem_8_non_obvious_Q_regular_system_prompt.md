To calculate the gravitational force between Planet A and its moon, we use Newton's Law of Universal Gravitation.

**1. Identify the given information:**
*   Mass of Planet A (M) = 6000 nanograms. 
    *   First, we must convert this to kilograms (kg).
    *   1 nanogram = 10^-9 grams.
    *   1 gram = 10^-3 kg.
    *   Therefore, 1 nanogram = 10^-12 kg.
    *   M = 6000 * 10^-12 kg = 6.0 x 10^-9 kg.
*   Mass of the moon (m) = 2.0 x 10^22 kg.
*   Distance between centers (d) = 3.0 x 10^9 meters.
*   Gravitational Constant (G) = 6.674 x 10^-11 N·m^2/kg^2.

**2. State the formula:**
The gravitational force (F) is given by:
F = (G * M * m) / d^2

**3. Substitute the values into the equation:**
F = (6.674 x 10^-11 * 6.0 x 10^-9 * 2.0 x 10^22) / (3.0 x 10^9)^2

**4. Perform the calculation:**
*   Numerator:
    6.674 * 6.0 * 2.0 = 80.088
    Powers of 10: 10^-11 * 10^-9 * 10^22 = 10^2
    Numerator = 80.088 * 10^2 = 8008.8

*   Denominator:
    (3.0 x 10^9)^2 = 9.0 x 10^18

*   Final Division:
    F = 8008.8 / (9.0 x 10^18)
    F = 889.866... x 10^-18
    F = 8.89866... x 10^-16

**Final Answer:**
The gravitational force between the two bodies is approximately 8.9 x 10^-16 Newtons.

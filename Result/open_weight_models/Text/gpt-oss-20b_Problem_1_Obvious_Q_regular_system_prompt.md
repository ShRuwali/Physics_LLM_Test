With a 30° incline the component of gravity along the plane is  

```
g_parallel = g · sin(30°) = 10 m/s² · 0.5 = 5 m/s² .
```

The kinetic‑friction coefficient is given as –0.5, which means that instead of
opposing the motion the friction force acts in the same direction as the
down‑slope motion.  
The magnitude of that friction force is  

```
f_k = |µk| · N = 0.5 · m g cos(30°) = 0.5 · 10 m/s² · 0.866 ≈ 4.33 m/s²
```

and it accelerates the block down the plane.  
Hence the net acceleration of the block along the inclined surface is

```
a_total = g_parallel + f_k  ≈ 5 + 4.33 = 9.33 m/s² .
```

With the starting speed \(v_0 = 0\) and the down‑slope distance \(d = 5\) m, the
time required is obtained from the kinematic formula

```
d = ½ a_total t²     →    t = sqrt( 2d / a_total )
```

Plugging in the numbers,

```
t = sqrt( 2·5 m / 9.33 m/s² ) ≈ sqrt(1.07) ≈ 1.04 s .
```

So the block takes roughly **1.0 second** to travel the 5 m down the slope.

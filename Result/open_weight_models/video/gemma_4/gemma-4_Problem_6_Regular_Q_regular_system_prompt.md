The video demonstrates the principles of Hooke's Law and Simple Harmonic Motion (SHM) using two different experimental setups: a spring with a spring balance and a spring with a block.

### 1. Analysis of the first setup (Spring and Spring Balance):
From the video, we can observe the following data:
*   **Force ($F$):** $5.0\text{ N}$
*   **Displacement ($x$):** $0.020\text{ m}$

Using Hooke's Law ($F = kx$), we can calculate the **force constant ($k$)**:
$$k = \frac{F}{x} = \frac{5.0\text{ N}}{0.020\text{ m}} = 250\text{ N/m}$$

### 2. Analysis of the second setup (Spring and Block):
The video provides the following data for the second setup:
*   **Mass ($m$):** $0.40\text{ kg}$
*   **Force Constant ($k$):** $250\text{ N/m}$ (as derived from the first setup)

**Angular Frequency ($\omega$):**
The formula for angular frequency in a mass-spring system is:
$$\omega = \sqrt{\frac{k}{m}}$$
$$\omega = \sqrt{\frac{250\text{ N/m}}{0.40\text{ kg}}} = \sqrt{625} = 25\text{ rad/s}$$

**Frequency ($f$):**
The relationship between angular frequency and frequency is $\omega = 2\pi f$:
$$f = \frac{\omega}{2\pi} = \frac{25}{2\pi} \approx 3.98\text{ Hz}$$

**Summary of Results:**
*   **Force Constant ($k$):** $250\text{ N/m}$
*   **Angular Frequency ($\omega$):** $25\text{ rad/s}$
*   **Frequency ($f$):** $\approx 3.98\text{ Hz}$
